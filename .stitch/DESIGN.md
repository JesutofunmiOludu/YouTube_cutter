# Design System for YouTube Cutter

## 🎨 Brand Identity
- **Name**: YouTube Cutter
- **Vibe**: Dark, sophisticated, cinematic — deep blacks with vibrant accent pops

## 🎨 Color System
- **Background**: Deep Void Black (#0A0A0F) - For main canvas
- **Surface**: Elevated Charcoal (#13131A) - For cards and panels
- **Surface Raised**: Midnight Slate (#1C1C28) - For elevated containers
- **Primary Accent**: Electric Indigo (#5C6BFF) - For primary buttons, highlights, active states
- **Secondary Accent**: Vivid Cyan (#00D4FF) - For timeline selection range, time markers
- **Success/Approved**: Emerald Mint (#00C48C) - For approved/completed badges
- **Warning/Attention**: Warm Amber (#FFB020) - For pending/editable states
- **Destructive/Cut**: Coral Red (#FF4757) - For cut action buttons

## 📝 Typography
- **Primary**: SF Pro Display (headings) / SF Pro Text (body)
- **Technical/Mono**: Monospace (timestamps/code)

## 📐 Layout & Components
- **Border Radius**: 
  - Buttons: Rounded pill shape (24px radius)
  - Cards: 16px radius with subtle 1px border (#2A2A3E)
- **Floating Action Bubble**: 56px circle, Electric Indigo (#5C6BFF) with white icon, pulsing shadow
- **Bottom Navigation**: Frosted glass effect, blur 24px, dark base with 5 icon tabs

## 💡 Design System Notes for Stitch Generation
When generating screens for YouTube Cutter, strictly adhere to the following:
- Platform: Mobile (iOS-style), Mobile-first
- Theme: Dark, sophisticated, cinematic — deep blacks with vibrant accent pops
- Background: Deep Void Black (#0A0A0F)
- Surface: Elevated Charcoal (#13131A) for cards/panels, Midnight Slate (#1C1C28) for elevated containers
- Primary Accent: Electric Indigo (#5C6BFF)
- Secondary Accent: Vivid Cyan (#00D4FF)
- Buttons: Rounded pill shape (24px radius)
- Cards: 16px radius with 1px border (#2A2A3E)
- Use SF Pro font, and monospace for timestamps
- Add a floating action bubble at the bottom-right
